# Superstore-Sales-Analysis
📌 Project Overview : 
    This project analyzes Superstore sales data using Microsoft Excel to uncover insights related to sales performance, profit trends, customer segments, and regional performance. 
    The analysis helps understand business growth patterns and supports data-driven decision-making.

🛠️ Tools & Technologies :
    Microsoft Excel
    Pivot Tables
    Pivot Charts
    Power Query (for data cleaning)
    Excel Functions (IF, SUMIFS, VLOOKUP/XLOOKUP)
    Conditional Formatting

📂 Dataset Description :
    The dataset includes sales records with the following key fields:
    Order ID
    Order Date
    Customer Name
    Segment
    Region
    Category
    Sub-Category
    Sales
    Profit
    Quantity
    Discount

🎯 Objectives :
   Analyze overall sales and profit performance
   Identify top-performing products and categories
   Study region-wise and segment-wise sales
   Analyze impact of discounts on profit
   Track monthly and yearly sales trends

🧹 Data Cleaning & Preparation :
    Removed duplicate records
    Handled missing and inconsistent values
    Created calculated columns (Profit Margin, Year, Month)
    Standardized date and currency formats
    Used Power Query for structured data cleaning

📊 Analysis Performed :
   Sales & profit by Category and Sub-Category
   Region-wise and Segment-wise performance
   Top 10 products by sales and profit
   Discount vs Profit analysis
   Time-series analysis (monthly & yearly trends)

📈 Dashboards & Visualizations :
    Interactive Excel dashboard using Pivot Charts
    KPI cards for Total Sales, Total Profit, and Orders
    Bar and Column charts for category performance
    Line charts for sales trends
    Slicers for Region, Category, and Segment filtering
